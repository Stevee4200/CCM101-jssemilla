# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

For me, the **compute component** is one of the most important parts of cloud infrastructure because it provides the processing power required to run applications, services, and other workloads. Without resources such as the CPU and memory, cloud systems would not be able to perform their tasks. Selecting the right compute resources is also important because it can affect the system's performance, reliability, and overall cost.

## 2. How does Linux support cloud computing?

Linux plays an important role in cloud computing by providing a reliable, secure, flexible, and efficient operating system for cloud servers. It can work with different hardware and can be managed easily through command-line tools. During this laboratory activity, I used Linux commands to check the CPU, memory, storage, disk usage, and network settings of the system. Linux is widely used in cloud environments because it is customizable and easy to manage efficiently.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important before deployment because it keeps a clear record of the system's infrastructure, configurations, requirements, and procedures. It can help reduce errors and make problems easier to identify and solve. Documentation also helps team members understand how the system works and allows them to recreate the same configuration when necessary.

## 4. What new skills did you learn during this laboratory activity?

During this laboratory activity, I learned how to use Linux terminal commands to examine the resources of a cloud server. I also learned how to organize technical information using Markdown, create and manage files in Ubuntu, and use Git commands to track changes. These activities helped improve my knowledge of Linux administration and cloud infrastructure.
