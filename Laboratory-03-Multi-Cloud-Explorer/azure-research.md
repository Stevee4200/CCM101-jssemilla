# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services that organizations can use to build, deploy, manage, and scale applications. Azure supports computing, storage, networking, databases, security, artificial intelligence, and other cloud technologies.

## Global Infrastructure

Azure provides a global cloud infrastructure with Regions, Availability Zones, and data centers located around the world. This infrastructure allows organizations to deploy applications closer to their users and improve availability and performance.

## Cloud Management Console

The Microsoft Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources. Users can manage virtual machines, storage, networks, databases, security settings, and other Azure services through the portal.

Official Azure Portal:

https://learn.microsoft.com/azure/

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual servers that organizations can use to run applications and workloads.

### 2. Azure Blob Storage

Azure Blob Storage provides scalable object storage for files, documents, backups, and other unstructured data.

### 3. Azure Virtual Network

Azure Virtual Network allows organizations to create private networks and connect Azure resources securely.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users and applications. It helps organizations control access to cloud resources and applications.

## Three Advantages

1. **Microsoft integration** – Azure works well with Microsoft products and technologies.
2. **Scalability** – Organizations can increase or decrease resources according to their needs.
3. **Security and compliance** – Azure provides security and compliance features for enterprise environments.

## Typical Enterprise Use Cases

Azure is commonly used by organizations for hosting applications, running Windows and Linux servers, storing business data, supporting Microsoft services, creating backup solutions, and developing enterprise applications.
