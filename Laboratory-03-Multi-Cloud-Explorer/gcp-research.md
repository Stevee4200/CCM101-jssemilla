## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is a cloud computing platform provided by Google. It offers services for computing, storage, networking, databases, artificial intelligence, machine learning, and application development.

## Global Infrastructure

Google Cloud operates a global infrastructure consisting of regions and zones located around the world. Its global network helps organizations deploy applications and services while providing reliable connectivity and reduced network latency.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. Users can create and manage virtual machines, storage, networks, databases, security settings, and other cloud resources.

Official Google Cloud Console:

https://docs.cloud.google.com/

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that allow organizations to run applications and workloads on Google's infrastructure.

### 2. Cloud Storage

Cloud Storage provides object storage for files, backups, application data, and other information.

### 3. Virtual Private Cloud (VPC)

Google Cloud VPC provides networking capabilities that allow organizations to connect and manage cloud resources securely.

### 4. Cloud IAM

Cloud Identity and Access Management (IAM) allows organizations to control access to Google Cloud resources by managing identities, roles, and permissions.

## Three Advantages

1. **Strong AI and machine learning capabilities** – Google Cloud provides many services and tools for AI and machine learning.
2. **Global network** – Google operates a large global network that supports cloud applications and services.
3. **Scalability** – Cloud resources can be adjusted according to application and business requirements.

## Typical Enterprise Use Cases

Google Cloud is commonly used for hosting applications, data analytics, artificial intelligence and machine learning, storage, databases, website hosting, and containerized applications.
