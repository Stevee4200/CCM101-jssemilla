# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many cloud services that organizations can use to build, deploy, store, and manage applications without maintaining all of the physical hardware themselves. AWS provides services for computing, storage, databases, networking, security, analytics, and many other purposes.

## Global Infrastructure

AWS has a large global infrastructure made up of Regions, Availability Zones, and data centers. Organizations can choose different AWS Regions to deploy their applications based on location, performance, and availability requirements.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. It allows users to create and manage resources, monitor services, manage users, and view billing information.

Official AWS Management Console:
https://aws.amazon.com/console/

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides object storage for files, data, backups, and other information.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create an isolated virtual network for their AWS resources.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls who can access AWS resources and what actions they are allowed to perform.

## Three Advantages

1. **Wide range of services** – AWS provides many services for different computing and business requirements.
2. **Scalability** – Resources can be increased or decreased depending on the workload.
3. **Global availability** – AWS provides infrastructure in many locations around the world.

## Typical Enterprise Use Cases

AWS is commonly used by organizations for hosting websites and applications, storing business data, running databases, creating backup systems, and supporting large-scale enterprise applications.
