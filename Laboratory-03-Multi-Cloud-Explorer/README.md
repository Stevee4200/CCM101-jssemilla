## ☁️ Cloud Infrastructure Components

The main cloud infrastructure components explored in this laboratory are:

### Compute

Compute resources provide the processing power needed to run applications and workloads.

**Example:** CPU / Virtual Machine

### Storage

Storage resources are used to save files, application data, backups, and other information.

**Example:** Amazon S3, Azure Blob Storage, and Google Cloud Storage

### Networking

Networking connects users, applications, servers, and other cloud resources.

**Example:** AWS VPC, Azure Virtual Network, and Google Cloud VPC

### Operating System

The operating system manages hardware and software resources and provides an environment for applications and services.

**Example:** Ubuntu Linux

## 🌐 Cloud Platforms Explored

### Amazon Web Services (AWS)

AWS is a major cloud computing platform that provides a wide range of services for computing, storage, networking, databases, security, and other technologies.

### Microsoft Azure

Microsoft Azure is a cloud platform developed by Microsoft. It provides strong integration with Microsoft technologies and services.

### Google Cloud Platform (GCP)

Google Cloud provides cloud services for computing, storage, networking, databases, Artificial Intelligence, Machine Learning, and Kubernetes.

## 🔧 Core Cloud Services Compared

| Service Category | AWS | Microsoft Azure | Google Cloud |
|---|---|---|---|
| **Virtual Machine** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Object Storage** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Identity Management** | AWS IAM | Microsoft Entra ID | Cloud IAM |
| **SQL Database** | Amazon RDS | Azure SQL Database | Cloud SQL |
| **Kubernetes** | Amazon EKS | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

## 🏢 Cloud Platform Recommendations

Different organizations have different cloud requirements.

| Client | Recommended Platform | Main Reason |
|---|---|---|
| **Startup Company** | Google Cloud Platform | Scalable services for growing applications |
| **University** | Microsoft Azure | Strong Microsoft integration |
| **AI Research Company** | Google Cloud Platform | Strong AI and Machine Learning capabilities |
| **Global E-Commerce Company** | AWS | Global infrastructure and scalability |

---

## 📊 Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| **Startup Company** | Google Cloud Platform | Provides scalable services that can support business growth |
| **Enterprise Organization** | AWS | Offers a broad range of services and global infrastructure |
| **Microsoft Environment** | Microsoft Azure | Integrates well with Microsoft technologies |
| **AI / Machine Learning** | Google Cloud Platform | Provides strong AI and Machine Learning services |
| **Kubernetes Deployment** | Google Cloud Platform | Provides Google Kubernetes Engine (GKE) and strong Kubernetes support |
| **Global Web Application** | AWS | Provides global infrastructure, high availability, and scalability |
