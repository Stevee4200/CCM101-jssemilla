# Laboratory 08 – Mission Reflection

Completing this Cloud Security Engineer laboratory helped me understand the importance of protecting servers and managing network security. I learned that a host-based firewall provides an additional layer of protection even if the physical network firewall or perimeter is breached. It protects the individual server by controlling incoming and outgoing connections based on configured security rules. This means that unauthorized users cannot easily access services that are not permitted.

Managing open network ports is also important because every open port can become a possible entry point for attackers. By allowing only the necessary ports and blocking unused ones, we can reduce the server's attack surface and improve its security. For example, leaving a database port such as 3306 for MySQL open to the public internet is dangerous because attackers could attempt to access the database, steal sensitive information, or exploit weak passwords and vulnerabilities.

This mission changed my perspective on how easily a server can be compromised. Before completing this activity, I thought that deploying a web server was mostly about making an application accessible to users. Now, I understand that proper security configurations are equally important. Even a simple mistake, such as forgetting to configure firewall rules, can expose a server to possible attacks.

Looking at my GitHub portfolio with eight completed missions, I feel proud of the progress I have made in learning cloud computing. Each mission helped me improve my knowledge of Linux commands, Docker, server management, networking, and cloud security. My repository also serves as evidence of my activities, screenshots, documentation, and practical experience.

Overall, this laboratory taught me that security should always be considered when building and managing cloud infrastructure. As a future IT professional, I will apply these practices to help protect systems, applications, and important data.
