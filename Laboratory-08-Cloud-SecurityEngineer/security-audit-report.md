# Security Audit Report

## Chapter 8: Security Best Practices

### 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the permissions they need to perform their assigned tasks. It is important in cloud accounts because it prevents users from accessing sensitive information or changing system settings that are not related to their responsibilities. This helps reduce security risks if an account is compromised.

### 2. Attack Surface

An attack surface refers to all the possible entry points that an attacker could use to access or attack a virtual machine. These include open ports, running services, applications, and user accounts. Reducing unnecessary services and closing unused ports can help make the virtual machine more secure.

### 3. Default Deny Policy

A Default Deny Policy means blocking all incoming or outgoing network traffic unless it is specifically allowed by a security rule. This is safer because it prevents unauthorized connections from accessing the system, even if the source of the threat is unknown. Instead of trying to identify and block every possible hacker, only trusted and necessary connections are permitted.
