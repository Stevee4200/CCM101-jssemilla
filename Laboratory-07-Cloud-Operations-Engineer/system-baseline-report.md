# System Baseline Report

## RAM Usage

The server has a total of **1.9 GiB of RAM**, with 493 MiB currently used and 1.4 GiB available. The `free -h` command was used to check the server's memory status in a human-readable format.

## Disk Storage

The total capacity of the root filesystem (`/`) will be recorded after running the `df -h /` command.

## Why Is Checking Disk Space Important?

Checking disk space before a major traffic surge is important because the server needs enough storage for application files, logs, temporary files, and other system operations.

## CPU and Running Processes

The `top` command will be used to observe CPU utilization, system load, and active processes.
