# Laboratory 5 - The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I will learn about cloud storage and deploy an S3-compatible object storage server using MinIO and Docker. I will create a storage bucket named `client-photos` and upload a sample file to test the storage system.

## Objectives

- Differentiate between Block Storage, File Storage, and Object Storage.
- Deploy MinIO using Docker.
- Access the MinIO Web Console through port forwarding.
- Create a storage bucket and upload a file.
- Document the deployment using Markdown.
- Organize my work in my GitHub Cloud Computing Portfolio.

## Tools Used

- GitHub
- KillerCoda Playground
- Docker
- MinIO
- Web browser
- Markdown

## Skills Learned

- Linux command-line operations
- Docker container deployment
- Cloud object storage management
- Port forwarding and web console access
- Creating buckets and uploading objects
- Technical documentation using Markdown
