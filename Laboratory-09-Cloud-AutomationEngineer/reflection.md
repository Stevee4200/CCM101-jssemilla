# Laboratory 09 – Mission Reflection

Completing this Cloud Automation Engineer laboratory helped me understand why automation is important in cloud computing. Managing hundreds of cloud servers manually would take a lot of time and effort. Automation allows administrators to perform repetitive tasks, such as backups and maintenance, more efficiently. However, automation also has potential dangers. For example, if a script contains a destructive typo and runs on 1,000 servers, it could accidentally delete important files or damage multiple systems. This is why scripts should always be tested and checked before scheduling or deploying them.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash scripting focuses on executing commands step by step to perform tasks, such as creating folders and backing up files. On the other hand, Docker Compose uses YAML to define and manage multiple containers, such as Nextcloud and MariaDB. Both tools are useful because they help automate tasks and reduce manual work.

Looking back at my GitHub repository from Laboratory 1 to Laboratory 9, I can see how much my understanding of cloud computing has improved. At first, I only had basic knowledge of cloud services and Linux commands. As I completed each mission, I learned about infrastructure management, Docker, storage, deployment, monitoring, security, and automation. I also became more confident using the Linux terminal and documenting my activities in GitHub.

Among the different roles, I enjoyed the Cloud-Native Engineer role the most because I was able to work with Docker containers and understand how applications and services work together. It was interesting to see how different containers can communicate and support an application.

Overall, this semester taught me that cloud computing involves more than simply running applications online. It requires proper planning, security, monitoring, and automation. These experiences will help me improve my IT skills and prepare for my future career.
